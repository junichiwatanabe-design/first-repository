# first-repository

特定の Google ドライブフォルダにある複数のスプレッドシートファイル（ファイル名に日付を含む、案件ごとの帳票）から、
指定した起点日付を基準に5日分の案件を抽出し、集計用スプレッドシート内に「1案件＝1タブ」として
書き出す Google Apps Script（GAS）プロジェクト。Google Sheets には保存される改ページ機能が無いため、
印刷時に案件単位で改ページされるよう、案件ごとに別タブへ分けている。

## 構成ファイル

- `Code.gs` — メインロジック
- `appsscript.json` — GAS マニフェスト（タイムゾーン、必要スコープ）
- `.clasp.json` — [clasp](https://github.com/google/clasp) 用設定。`scriptId` は実際の
  Apps Script プロジェクトの ID に書き換えてください

## セットアップ

1. 集計に使いたい Google スプレッドシートを開き、拡張機能 > Apps Script でスクリプトエディタを開く
2. このリポジトリの `Code.gs` と `appsscript.json` の内容をコピーし、スクリプトエディタ側の
   `コード.gs` / `appsscript.json` に貼り付ける（もしくは `clasp` で `.clasp.json` の
   `scriptId` を書き換えた上で `clasp push`）
3. 対象スプレッドシートを開き直す（または再読み込み）と、メニューに「日次データ取込」が追加される

## 使い方

1. 初回実行時、自動的に「設定」という名前のシートが作成される（作成直後は入力を促すアラートが出て処理は中断する）
2. 「設定」シートに以下を入力する

   | セル | 内容 | 例 |
   |------|------|----|
   | B1 | 対象フォルダの URL または フォルダID | `https://drive.google.com/drive/folders/xxxxxxxx` |
   | B2 | 各ファイル内で読み込む固定タブ名 | `Sheet1` |
   | B3 | 起点日付 | `2026/07/13` |

3. メニュー「日次データ取込」→「5日分読み込み実行」を実行する
4. 起点日付から連続5日分（起点日を含む）について、フォルダ内のスプレッドシートファイルのうち
   ファイル名にその日付（`yyyy.M.d` 形式、例: `2026.7.13`）を含むものをすべて検出し、
   各ファイルの指定タブのデータ（使用済み範囲全体）を読み込む
5. マッチした案件（ファイル）ごとに、集計用スプレッドシート内に個別のタブを作成する。
   タブ名は「日付 + 企業名」（例: `2026.7.15 APPREA`）。企業名が読み取れない場合はファイル名を使う。
   同じ日付のタブは実行のたびに一旦すべて削除してから作り直すため、再実行しても重複・古いタブが残らない
6. 各タブには以下の書式が自動で適用される（ラベル文字列を検索して該当セルに適用するため、
   案件シートの行位置が多少ずれても崩れない）
   - シート全体の基本フォントサイズ: 14pt
   - 「案件実施日」「企業名」の値セル: 20pt・太字
   - 「参加人数」「パーティー目的」「プランナー」の値セル: 16pt・太字
   - 「メニュー名」「数量」の列（メニュー表の見出し行より下、シート最終行まで）: 20pt・太字
   - メニュー表の見出し行: 太字＋薄いグレー背景
   - メニュー表のデータ行: 薄い交互背景（バンディング）
   - 「温製」「ベジ」列: チェックボックス化し、チェック済み（TRUE）のセルは薄い赤背景で強調
   - 「メニュー名」セルは3列分（E:G相当）を横結合し、長いメニュー名でも読みやすくする
     （データ行ごとに個別結合。行同士が縦に結合されることはない）
7. 列のレイアウトも自動調整される
   - A列・D列・J列は非表示
   - B列・C列（温製・ベジ）の幅は30px
   - F列（案件実施日・企業名などの値が入る列）の幅は500px
   - N列（時刻）は `H:mm` 形式（例: `8:00`）で表示
8. 印刷する際は、複数タブを選択して「ファイル > 印刷 > 選択したシート」から一括印刷すると、
   タブ（＝案件）の境目で自動的に改ページされる
9. 実行完了後、日付ごとの該当ファイル数・作成タブ数・タブ名・警告（タブが見つからない等）がダイアログで表示される

## 注意事項

- フォルダ内のファイルはすべて Google スプレッドシート形式であることを前提としている
- 集計用スプレッドシート自身が対象フォルダ内にある場合、自分自身は読み込み対象から自動的に除外される
- ファイル名の日付形式は `yyyy.M.d`（月日ともにゼロ埋めなし）を前提としている。異なる形式を使う場合は
  `Code.gs` の `formatDateForMatch_` を変更する
- 各案件ファイル内に「企業名」「案件実施日」「メニュー名」「数量」「温製」「ベジ」というラベル文字列が
  存在することを前提に書式を適用している。ラベルが見つからない項目は書式適用がスキップされる（エラーにはならない）
