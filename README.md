# first-repository

特定の Google ドライブフォルダにある複数のスプレッドシートファイル（ファイル名に日付を含む、案件ごとの帳票）から、
指定した起点日付を基準に数日分の案件を抽出して集計用スプレッドシートへコピーし（1機能）、
その集計結果から印刷用のメニューラベルを作る（もう1機能）、2つの機能を持つ
Google Apps Script（GAS）プロジェクト。

## 構成ファイル

- `Code.gs` — メインロジック。以下の4セクションに分かれている
  1. 設定シート関連
  2. 日次データ取込（集計用スプレッドシートへの案件タブ作成）
  3. 印刷用ラベル作成
  4. 共通ヘルパー
- `appsscript.json` — GAS マニフェスト（タイムゾーン、必要スコープ）
- `.clasp.json` — [clasp](https://github.com/google/clasp) 用設定。`scriptId` は実際の
  Apps Script プロジェクトの ID に書き換えてください

## セットアップ

1. 集計に使いたい Google スプレッドシートを開き、拡張機能 > Apps Script でスクリプトエディタを開く
2. このリポジトリの `Code.gs` と `appsscript.json` の内容をコピーし、スクリプトエディタ側の
   `コード.gs` / `appsscript.json` に貼り付ける（もしくは `clasp` で `.clasp.json` の
   `scriptId` を書き換えた上で `clasp push`）
3. 対象スプレッドシートを開き直す（または再読み込み）と、メニューに「日次データ取込」が追加される

## 設定シート

初回、いずれかのメニュー項目を実行すると自動的に「設定」シートが作成される
（作成直後は入力を促すアラートが出て処理は中断するので、再実行が必要）。

| セル | 内容 | 例 |
|------|------|----|
| B1 | 対象フォルダの URL または フォルダID | `https://drive.google.com/drive/folders/xxxxxxxx` |
| B2 | 各ファイル内で読み込む固定タブ名 | `Sheet1` |
| B3 | 起点日付 | `2026/07/13` |
| B4 | 読み込み日数（1〜5、空欄で5日） | `3` |
| B5 | ラベル出力先スプレッドシートの URL または ID（自動設定・空欄でOK。既存のスプレッドシートを使わせたい場合は手動で貼ってもよい） | （未入力のまま、または `https://docs.google.com/spreadsheets/d/xxxxxxxx/edit`） |

## 機能1: 日次データ取込（メニュー「日次データ取込」→「データ読込」）

起点日付から連続N日分（B4で指定した日数。未入力なら5日）について、フォルダ内の
スプレッドシートファイルからファイル名に該当日付を含むものを検出し、各ファイルの
指定タブを集計用スプレッドシート内へ案件ごとにコピーする。

- **ファイル名の日付表記のゆれに対応**: 区切り文字が `.` `/` `-` のいずれでも、
  月日がゼロ埋めされていてもいなくても検出できる（例: `2026.7.13` `2026/7/13`
  `2026-07-13` はすべて同じ日として一致する）。年は4桁固定を前提とする

- **タブ名**: 「日付 + 企業名」（例: `2026.7.15 APPREA`）。企業名が読み取れない場合はファイル名を使う
- **再実行時の挙動**: 実行のたびに「設定」シートを除く全ての案件タブ（前回までの
  処理対象日付が現在の範囲外になっていたものも含む）を一旦削除してから作り直すため、
  タブが際限なく増え続けることはない。前回までのデータは残らないので、必要であれば
  実行前に別途保存しておく
- **書式**: 各タブは元の案件ファイルのタブを `copyTo()` でそのまま複製したもので、
  フォントの種類・サイズ・太さ、背景色、罫線、セル結合、列幅、非表示列など
  元シートの書式を一切変更せずそのまま引き継ぐ。ただし「メニュー名」「数量」列の
  データ行（見出し行を除く）だけはフォントサイズを14pt（`CASE_MENU_FONT_SIZE`）に設定する
- **数式について**: セルの中身はコピー前に評価済みの値で上書きする（数式としては
  コピーしない）。元シートが他シート参照などの数式を含んでいても、コピー先で参照が
  切れて `#REF!` のようなエラーになることを防ぐため
- **印刷**: 複数タブを選択して「ファイル > 印刷 > 選択したシート」から一括印刷すると、
  タブ（＝案件）の境目で自動的に改ページされる
- **完了ダイアログ**: 「データ読込 結果」に日付ごとの作成件数・企業名が
  以下の形式で表示される。案件1件分の処理は個別に例外を捕捉しているため、
  ある案件でエラーが起きても他の案件・他の日付の処理は継続される
  ```
  2026.8.2 : 1件（旭化成）
  2026.8.5 : 該当ファイルなし
  ```
- **警告ダイアログ**: タブが見つからない・データがない・処理中にエラーが発生した
  等の警告が1件でもあれば、通常の結果に埋もれないよう「⚠️要確認」という
  別ダイアログで表示される（各行は「日付 企業名（またはファイル名） : 内容」の形式）
  ```
  ⚠️要確認
  2026.8.1 大都技研様 : タブ「案件シート」が見つかりません
  ```

## 機能2: 印刷用ラベル作成（メニュー「日次データ取込」→「ラベル作成」）

「設定」シートを除く現在存在する案件タブごとに、日付・企業名・メニュー名・数量を
集めて、ラベル専用の別スプレッドシート内に案件と同名のタブを作り、A4・24面
（A-one マルチプリンタ用ラベルシール、66mm×33.9mm、3列×8行）のラベルシールに
印刷できる形式で出力する。

### 出力先

初回実行時、ラベル専用の新しい Google スプレッドシート（名前は
「（集計用スプレッドシート名）（ラベル印刷）」）が集計用スプレッドシートと同じ
フォルダに自動作成され、その URL/ID が「設定」シートの B5 に保存される
（2回目以降はこの ID のファイルを再利用する）。

### タブと配置

- 各案件タブのメニュー表を走査し、メニュー名・数量がある行だけをラベル1件として集計する
  （複数の案件タブ＝複数日分をまとめて処理する）
- ラベル専用スプレッドシート内に「案件タブと同名のタブ」を1つずつ作成する
  （既に同名タブがあれば削除してから作り直すため、再実行しても古い内容が残らない。
  案件が無くなった場合、対応するタブも自動的に削除される）
- 1件につき縦に隣接する2行を使って同一内容を2枚配置する
  （3列×8行＝24枚＝12件で1ページ。13件目以降は次の8行ブロック＝次ページに続く）

### ラベル1枚のレイアウト

各ラベルは3段のセル（縦に3行分）で構成され、行の高さは常に固定
（データの長さによって自動で広がらない。はみ出した分は途中で切れる）。

| 段 | 内容 | 配置 | 備考 |
|----|------|------|------|
| 1段目 | `日付　企業名` | 左寄せ | 日付はゼロ埋めなし・年なしの `M/d` 形式（例: `7/16`）。元の値が `2026.7.16` や `2026/7/17` のように年付き・区切り文字違いでも統一される |
| 2段目 | メニュー名 | 左寄せ | 1段目より2pt小さいフォント。中央寄せだとはみ出した際に先頭が見えず分かりにくいため左寄せ |
| 3段目 | 数量 | 中央寄せ | 太字・大きめフォントで強調 |

列幅66mm・ラベル1枚あたりの高さ33.9mm（3段の内訳は34px/44px/50px）で列・行の
サイズを設定する。お使いのラベルシート商品の実寸がこれと異なる場合は、`Code.gs` の
`LABEL_COL_WIDTH_MM` / `LABEL_SUBROW_HEIGHTS_PX` を実際の値に合わせて調整する
（`LABEL_SUBROW_HEIGHTS_PX` の合計がラベル1枚の高さ（px）になる）。

### 印刷時の注意

1. ラベル専用スプレッドシートを開き、ファイル > 印刷でページの余白を上下約12mm・
   左右約5mm程度に設定し、拡大縮小は「なし（実際のサイズ）」にする
   - ラベル8枚分の高さは271.2mm（33.9mm×8）でA4の縦297mmとの差は25.8mm
     （片側12.9mm）しかないため、上下13mmちょうどだと0.2mm足りず最後の行が
     2ページ目にはみ出すことがある。12mm程度に少し余裕を持たせるとよい。
     それでも収まらない場合はさらに1〜2mm狭める
2. 最終ページで3列中1〜2列しか埋まらない場合でも3列とも印刷範囲に含まれるように
   しているが、それでも位置がずれる場合は印刷ダイアログの「書式設定 > 配置」が
   「中央」になっていないか確認し、「左」に変更する
3. まず普通紙に試し印刷し、現物のラベルシートと透かして位置がずれていないか
   確認してから本番のラベルシートに印刷することを推奨する

「ラベル作成 結果」ダイアログには、作成した案件数・メニュー件数・ラベル専用
スプレッドシートの URL が表示される。処理中にエラーが発生した案件があれば、
通常の結果に埋もれないよう「⚠️要確認」という別ダイアログで表示される。

## 注意事項

- フォルダ内のファイルはすべて Google スプレッドシート形式であることを前提としている
- 集計用スプレッドシート自身が対象フォルダ内にある場合、自分自身は読み込み対象から自動的に除外される
- ファイル名の日付は年4桁＋区切り文字（`.` `/` `-`）＋月日（ゼロ埋めあり/なしいずれも可）の
  形式を前提としている。これ以外の形式（年が2桁、区切り文字なし等）を使う場合は
  `Code.gs` の `buildFileNameDateRegex_` を変更する
