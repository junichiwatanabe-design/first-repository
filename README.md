# first-repository

「設定」シートに手入力した案件ファイルのURLを開き、ファイル名から案件実施日・
企業名を読み取るとともに、リンク先ファイル内の指定タブから直接（コピーせずに）
日付・企業名・メニュー名・数量を読み取って、印刷用のメニューラベルのHTMLを
生成し、ブラウザの印刷機能でそのまま印刷できるダイアログを表示する
Google Apps Script（GAS）プロジェクト。元の案件ファイルをコピーする工程も、
スプレッドシートへラベルを書き込む工程も持たないため、
**このスプレッドシート1枚だけで運用できる**。

## 構成ファイル

- `Code.gs` — メインロジック。以下の3セクションに分かれている
  1. 設定シート関連
  2. リンクからのラベル作成（HTML生成・印刷ダイアログ表示）
  3. 共通ヘルパー
- `appsscript.json` — GAS マニフェスト（タイムゾーン、必要スコープ）
- `.clasp.json` — [clasp](https://github.com/google/clasp) 用設定。`scriptId` は実際の
  Apps Script プロジェクトの ID に書き換えてください

## セットアップ

1. ラベルを作りたい Google スプレッドシート（新規でも既存のものでもよい。
   このシート自身に「設定」シートを作って使う）を開き、拡張機能 > Apps Script で
   スクリプトエディタを開く
2. このリポジトリの `Code.gs` と `appsscript.json` の内容をコピーし、スクリプトエディタ側の
   `コード.gs` / `appsscript.json` に貼り付ける（もしくは `clasp` で `.clasp.json` の
   `scriptId` を書き換えた上で `clasp push`）
3. 対象スプレッドシートを開き直す（または再読み込み）と、メニューに「ラベル作成」が追加される

## 設定シート

初回、メニュー「ラベル作成」→「作成」を実行すると自動的に「設定」シートが
作成される（作成直後は入力を促すアラートが出て処理は中断するので、再実行が
必要）。案件ファイルのURL一覧もこのシートの4行目以降にまとめて入力する（後述）。

| セル | 内容 | 例 |
|------|------|----|
| B1 | 各案件ファイル内で読み込む固定タブ名 | `案件シート` |
| B2 | 印刷時の余白の目安（メモ欄。スクリプトからは読み書きしない） | `上下12mm・左右5mm程度`（初期値。印刷ダイアログで余白を手動設定する際の目安として自由に書き換えてよい） |
| B3 | ラベルシールのサイズ（プルダウンで選択） | `3×8（66mm×33.9mm）`（初期値）または `3×6（66mm×45.2mm）` |
| A4 | 「案件ファイルのリンク一覧」の見出し行（自動設定） | `案件ファイルのリンク（1行に1件、URLを貼り付け）` |
| A5以降 | 案件ファイルのURL（手入力） | `https://docs.google.com/spreadsheets/d/xxxxxxxx/edit` |

※旧バージョンで使っていた「案件リンク一覧」という独立シートは廃止し、
「設定」シート1枚に統合した。1行目にタブ名の行が無い旧レイアウトの場合も、
次回「作成」実行時に自動的に新しいレイアウトへ移行されるので、手動での
調整は不要（既存のURL一覧などの入力済みデータは失われない）。

## 使い方（メニュー「ラベル作成」→「作成」）

1. 初回実行時、自動的に「設定」シートが作成される
   （作成直後は入力を促すアラートが出て処理は中断するので、B1に読み込む
   タブ名を、4行目以降のA列に案件ファイルのURLを1行に1件貼り付けてから
   再度実行する）
   - URLは `docs.google.com/spreadsheets/d/<ID>/edit`・`drive.google.com/file/d/<ID>/view`・
     `drive.google.com/open?id=<ID>` のいずれの形式でも認識する（`extractSpreadsheetId_`）
   - URL・スプレッドシートIDに加えて、**リンクの代わりにファイル名をそのまま
     貼ってしまった場合**もDrive内をそのファイル名で検索して開く救済策がある
     （`resolveLinkedSpreadsheet_`）。ただし同名ファイルが複数ある場合は最初に
     見つかったものが使われるため、確実に特定のファイルを指定したい場合は
     URLを貼ることを推奨する
2. メニュー「ラベル作成」→「作成」を実行する
3. 「設定」シートの4行目以降のA列のURLを1件ずつ開き、リンク先ファイルの**ファイル名**
   （Driveのファイル名）から案件実施日・企業名を読み取る
   - **ファイル名の日付表記のゆれに対応**: 区切り文字が `.` `/` `-` のいずれでも、
     月日がゼロ埋めされていてもいなくても検出できる（例: `2026.7.13` `2026/7/13`
     `2026-07-13` はすべて同じ日として扱われる）。区切り文字が無い `yyyyMMdd` の
     8桁連結表記（例: `20260713`。この場合は月日とも2桁ゼロ埋め固定）にも対応する。
     年は4桁固定を前提とする。日付が見つからない場合は空欄になり、ファイル名全体を
     企業名として扱う
   - ファイル名の前後の「【】」「[]」は取り除いて企業名とする
4. リンク先ファイル内の「設定」シートB1で指定したタブ名のシートから、
   **コピーせずに直接**日付・企業名・メニュー名・数量を読み取る
   （`collectLabelEntries_`。「案件実施日」「企業名」というラベル文字列が
   入ったセルの右隣の値、および「メニュー名」見出しを含む表のメニュー名・
   数量列を使う。これは手順3のファイル名解析とは別の、各案件ファイル自身の
   セル内容を読む処理）
5. 案件ファイルごとに読み取った内容を「案件実施日 + 企業名」の見出し付きで
   まとめ、すべての案件・すべてのラベルを含んだ1つのHTMLダイアログ
   （印刷プレビュー）を表示する（スプレッドシートへの書き込みは行わない）
6. **警告ダイアログ**: タブが見つからない・データがない・処理中にエラーが
   発生した等の警告が1件でもあれば、印刷ダイアログより先に「⚠️要確認」
   という別ダイアログで表示される
   ```
   ⚠️要確認
   【2026.8.1大都技研様】案件シート : タブ「案件シート」が見つかりません
   ```
7. **印刷ダイアログ**: タイトルに案件数が表示される。各案件の先頭には
   案件名・件数の見出し（画面確認用。印刷時には表示されない）が入っている。
   ダイアログ上部には以下の操作項目がある。
   - **開始位置**: 使いかけのラベルシート（一部のラベルが既に使用済み）の
     続きから印刷したい場合、「何枚目から印刷するか」を指定する。最初の
     案件の最初のページだけに適用され、それ以降のページ・案件は通常通り
     1枚目の面から埋まる
   - **ずれ補正（横・縦）**: プリンタの印字位置が実際のラベルシートと
     mm単位でずれている場合に微調整する
   - いずれも数値を変更するとサーバーに問い合わせず、その場で画面表示が
     再計算される。「NN枚 / 用紙M枚」の件数表示も連動して更新される
     （開始位置を変えても印刷される実データの枚数（NN）自体は変わらない）
   - 内容を確認したら「印刷」ボタンを押すとブラウザの印刷ダイアログが開く。
     用紙サイズ・余白はそのブラウザの印刷ダイアログ側で調整する

## ラベル1枚のレイアウト

各案件ファイルのメニュー表を走査し、メニュー名・数量がある行だけをラベル1件
として集計し、A-one マルチプリンタ用ラベルシールに印刷できる形式のHTMLを
生成する。面付けは「設定」シートB3のプルダウンで、A4・24面
（66mm×33.9mm、3列×8行）とA4・18面相当（66mm×45.2mm、3列×6行）のどちらかを
選べる（未選択の場合は24面）。1件につき縦に隣接する2行を使って同一内容を
2枚配置する（24面選択時: 3列×8行＝24枚＝12件で1ページ、13件目以降は次ページに
続く。18面相当選択時: 3列×6行＝18枚＝9件で1ページ、10件目以降は次ページに続く）。
面付けはCSS Grid（`grid-auto-flow: column`）で1列を上から埋めてから次の列へ
進む順に配置される。

各ラベルは3段（縦に3分割）で構成され、各段の高さは常に固定（データの長さに
よって自動で広がらない）。1段目・3段目は折り返さず、はみ出した分は途中で
切れる。2段目（メニュー名）だけは2行まで表示し、それを超える分は省略記号
「…」で省略される（`-webkit-line-clamp: 2`）。

| 段 | 内容 | 配置 | 備考 |
|----|------|------|------|
| 1段目 | `日付 企業名 様`（半角スペース区切り） | 左寄せ | 日付はゼロ埋めなし・年なしの `M/d` 形式（例: `7/16`）。元の値が `2026.7.16` や `2026/7/17` のように年付き・区切り文字違いでも、`2026年7月16日（木）` のような漢字区切りでも、末尾に曜日の注記（`（木）`等）が付いていても統一される（`normalizeDateText_`）。企業名・メニュー名のセルに改行が入っていても半角スペースに変換される（`normalizeLabelText_`）ほか、HTML上の折り返し処理でも通常の空白として扱われるため改行として表示されない。折り返さず固定高さのため、文字数が多い場合は末尾（「様」を含む）が切れる |
| 2段目 | メニュー名 | 中央寄せ | 1段目より2pt小さいフォント。2行まで表示し、それを超える分は自動的に省略記号で省略される |
| 3段目 | 数量 | 中央寄せ | 太字・大きめフォントで強調。折り返さず固定高さ |

列幅は66mmで共通。ラベル1枚あたりの高さは「設定」シートB3の選択に応じて
24面＝33.9mm（3段の内訳9.0mm/12.7mm/12.2mm）、18面相当＝45.2mm
（内訳11.9mm/16.9mm/16.4mm）のいずれかになる。お使いのラベルシート商品の
実寸がこれと異なる場合は、`Code.gs` の `LABEL_WIDTH_MM` / `LABEL_SIZE_PRESETS`
を実際の値（mm）に合わせて調整する（各プリセットの `segmentHeightsMm` の
合計がラベル1枚の高さ（mm）になる）。

## 印刷時の注意

1. 印刷ダイアログ（HTMLダイアログ上部の「印刷」ボタンから開く）で、
   ページの余白を上下約12mm・左右約5mm程度に設定し、拡大縮小は
   「なし（100%）」にする
   - ラベル1ページ分の高さはどちらのサイズを選んでも271.2mm
     （24面: 33.9mm×8行、18面相当: 45.2mm×6行）で共通。A4の縦297mmとの差は
     25.8mm（片側12.9mm）しかないため、上下の余白は12mm程度に収めるとよい
2. 最終ページで3列中1〜2列しか埋まらない場合も、CSS Gridの行列数が
   固定されているため3列分のレイアウトが保たれる（空の列が縮んで中央寄せが
   ずれることはない）
3. まず普通紙に試し印刷し、現物のラベルシートと透かして位置がずれていないか
   確認してから本番のラベルシートに印刷することを推奨する

## 注意事項

- 案件実施日・企業名（ラベルタブの命名用）は案件ファイルの**ファイル名**から
  読み取る（ファイル内のセルは読まない）。これ以外の形式（年が2桁、区切り
  文字なし等）を使う場合は `Code.gs` の `extractDateAndCompanyFromFileName_`
  を変更する
- ラベルの内容（「案件実施日」「企業名」「メニュー名」「数量」）は各案件
  ファイル自身のセル内容から読み取る。これはファイル名解析とは別の処理
  （`collectLabelEntries_`）
