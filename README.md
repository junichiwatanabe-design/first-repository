# first-repository

「設定」シートに手入力した案件ファイルのURLから、案件実施日・企業名を
ファイル名から読み取って集計用スプレッドシートへ案件ごとにタブとしてコピーし
（機能1）、その集計結果から印刷用のメニューラベルを作る（機能2）、
Google Apps Script（GAS）プロジェクト。

## 構成ファイル

- `Code.gs` — メインロジック。以下の4セクションに分かれている
  1. 設定シート関連
  2. リンクからの案件読み込み
  3. 印刷用ラベル作成
  4. 共通ヘルパー
- `appsscript.json` — GAS マニフェスト（タイムゾーン、必要スコープ）
- `.clasp.json` — [clasp](https://github.com/google/clasp) 用設定。`scriptId` は実際の
  Apps Script プロジェクトの ID に書き換えてください

## セットアップ

1. 集計に使いたい Google スプレッドシートを開き、拡張機能 > Apps Script でスクリプトエディタを開く
2. このリポジトリの `Code.gs` と `appsscript.json` の内容をコピーし、スクリプトエディタ側の
   `コード.gs` / `appsscript.json` に貼り付ける（もしくは `clasp` で `.clasp.json` の
   `scriptId` を書き換えた上で `clasp push`）
3. 対象スプレッドシートを開き直す（または再読み込み）と、メニューに「日次データ取込」が追加される

## 設定シート

初回、いずれかのメニュー項目を実行すると自動的に「設定」シートが作成される
（作成直後は入力を促すアラートが出て処理は中断するので、再実行が必要）。
案件ファイルのURL一覧もこのシートの5行目以降にまとめて入力する（後述）。

| セル | 内容 | 例 |
|------|------|----|
| B1 | ラベル出力先スプレッドシートの URL または ID（自動設定・空欄でOK。既存のスプレッドシートを使わせたい場合は手動で貼ってもよい） | （未入力のまま、または `https://docs.google.com/spreadsheets/d/xxxxxxxx/edit`） |
| B2 | 印刷時の余白の目安（メモ欄。スクリプトからは読み書きしない） | `上下12mm・左右5mm程度`（初期値。印刷ダイアログで余白を手動設定する際の目安として自由に書き換えてよい） |
| A4/B4 | 「案件ファイルのリンク一覧」の見出し行（自動設定） | `案件ファイルのリンク（1行に1件、URLを貼り付け）` / `ファイル名` |
| A5以降 | 案件ファイルのURL（手入力） | `https://docs.google.com/spreadsheets/d/xxxxxxxx/edit` |
| B5以降 | リンク先ファイルの名前（自動表示。手入力不要） | （「リンクから読込」実行時に自動入力される） |

※読み込むタブ名を固定指定する設定は廃止した。リンク先ファイルの**全タブ**を
読み込むため、タブ名を気にする必要はない（後述）。旧バージョンの「案件リンク
一覧」という独立シートも廃止し、「設定」シート1枚に統合した。いずれも次回
「リンクから読込」実行時に自動的に新しいレイアウトへ移行されるので、手動での
調整は不要（既存のラベルSS ID・URL一覧などの入力済みデータは失われない）。

## 機能1: リンクからの案件読み込み（メニュー「日次データ取込」→「リンクから読込」）

1. 初回実行時、自動的に「設定」シートが作成される
   （作成直後は入力を促すアラートが出て処理は中断するので、
   5行目以降のA列に案件ファイルのURLを1行に1件貼り付けてから再度実行する）
   - URLは `docs.google.com/spreadsheets/d/<ID>/edit`・`drive.google.com/file/d/<ID>/view`・
     `drive.google.com/open?id=<ID>` のいずれの形式でも認識する（`extractSpreadsheetId_`）
   - URL・スプレッドシートIDに加えて、**リンクの代わりにファイル名をそのまま
     貼ってしまった場合**もDrive内をそのファイル名で検索して開く救済策がある
     （`resolveLinkedSpreadsheet_`）。ただし同名ファイルが複数ある場合は最初に
     見つかったものが使われるため、確実に特定のファイルを指定したい場合は
     URLを貼ることを推奨する
2. メニュー「日次データ取込」→「リンクから読込」を実行する
3. 「設定」シートの5行目以降のA列のURLを1件ずつ開き、リンク先ファイルの**ファイル名**
   （Driveのファイル名。ファイル内のセルの中身は見ない）から案件実施日・企業名を
   読み取り、リンク先ファイルの**全タブ**の内容を集計用スプレッドシートへ
   案件ごとにタブとしてコピーする（固定のタブ名を指定する必要はない）
   - **ファイル名の日付表記のゆれに対応**: 区切り文字が `.` `/` `-` のいずれでも、
     月日がゼロ埋めされていてもいなくても検出できる（例: `2026.7.13` `2026/7/13`
     `2026-07-13` はすべて同じ日として扱われる）。区切り文字が無い `yyyyMMdd` の
     8桁連結表記（例: `20260713`。この場合は月日とも2桁ゼロ埋め固定）にも対応する。
     年は4桁固定を前提とする。日付が見つからない場合は空欄になり、ファイル名全体を
     企業名として扱う
   - ファイル名の前後の「【】」「[]」は取り除いて企業名とする
4. リンク先ファイルの名前（Driveのファイル名）を「設定」シートの同じ行の
   B列に表示する（診断用に、処理中にエラーが起きた場合を除きB列のファイル名は
   表示したままにする）。B列はA列にURLを貼っただけでは更新されず、
   「リンクから読込」を実行したタイミングで表示される
5. そのファイル名から読み取った「案件実施日 + 企業名」で名前をつけた案件タブを、
   リンク先ファイルの**タブごとに1つずつ**作成し、内容をそのままコピーする
   （1ファイルにタブが1枚しかない場合は「案件実施日 + 企業名」のみの名前になり、
   複数タブある場合は「案件実施日 + 企業名（元のタブ名）」のように元のタブ名を
   付記して区別する。例: `9.16 Spotify様（朝食）`）
   - **書式**: 元ファイルの各タブを `copyTo()` でそのまま複製したもので、
     フォントの種類・サイズ・太さ、背景色、罫線、セル結合、列幅、非表示列など
     元シートの書式を一切変更せずそのまま引き継ぐ。ただし「メニュー名」「数量」列の
     データ行（見出し行を除く）だけはフォントサイズを変更する
     （メニュー名13pt=`CASE_MENU_NAME_FONT_SIZE`、数量14pt=`CASE_QTY_FONT_SIZE`）
   - **数式について**: 数式が入っているセルは、コピー前に評価済みの値で上書きする
     （数式としてはコピーしない）。元シートが他シート参照などの数式を含んでいても、
     コピー先で参照が切れて `#REF!` のようなエラーになることを防ぐため。加えて、
     `IMPORTRANGE`・`QUERY`・`ARRAYFORMULA` など1セルの数式が周囲へ結果を
     展開する（スピルする）形式の場合、展開先のセル自体には数式が付いていない
     ため`copyTo()`では複製されず空欄になってしまう。元シートでは値があった
     のにコピー後は空欄になっているセルも同様に評価済みの値で埋める
     （`copyEvaluatedFormulaCells_`）。それ以外の、数式もなくコピー後も空欄で
     ないセル（時刻・日付など通常の入力値）は上書きしない。全セルを評価済みの
     値で上書きすると、Apps Scriptが値をいったんDateオブジェクトに変換してから
     書き込み先のタイムゾーンで解釈し直すため、リンク元ファイルと集計用
     スプレッドシートのタイムゾーン設定が異なる場合に時刻がズレてしまうため
   - **再実行時の挙動**: 実行のたびに「設定」を除く全ての案件タブを一旦削除してから
     作り直すため、タブが際限なく増え続けることはない。前回までのデータは残らないので、
     必要であれば実行前に別途保存しておく
6. **印刷**: 複数タブを選択して「ファイル > 印刷 > 選択したシート」から一括印刷すると、
   タブ（＝案件）の境目で自動的に改ページされる
7. **完了ダイアログ**: 「リンク読込 結果」に作成件数と、作成した案件タブ名の
   一覧が1行ずつ表示される。案件ファイル1件・タブ1枚ごとの処理は個別に例外を
   捕捉しているため、あるファイルやタブでエラーが起きても他の処理は継続される
8. **警告ダイアログ**: データがない・処理中にエラーが発生した等の警告が
   1件でもあれば、通常の結果に埋もれないよう「⚠️要確認」という別ダイアログで
   表示される
   ```
   ⚠️要確認
   【2026.8.1大都技研様】案件シート「デザート」 : データがありません
   ```

## 機能2: 印刷用ラベル作成（メニュー「日次データ取込」→「ラベル作成」）

「設定」を除く現在存在する案件タブごとに、日付・企業名・
メニュー名・数量を集めて、ラベル専用の別スプレッドシート内に案件と同名のタブを
作り、A4・24面（A-one マルチプリンタ用ラベルシール、66mm×33.9mm、3列×8行）の
ラベルシールに印刷できる形式で出力する。

### 出力先

初回実行時、ラベル専用の新しい Google スプレッドシート（名前は
「（集計用スプレッドシート名）（ラベル印刷）」）が集計用スプレッドシートと同じ
フォルダに自動作成され、その URL/ID が「設定」シートの B1 に保存される
（2回目以降はこの ID のファイルを再利用する）。

### タブと配置

- 各案件タブのメニュー表を走査し、メニュー名・数量がある行だけをラベル1件として集計する
  （複数の案件タブ＝複数日分をまとめて処理する）
- ラベル専用スプレッドシート内に「案件タブと同名のタブ」を1つずつ作成する
  （既に同名タブがあれば中身だけ消して再利用するため、再実行しても古い内容が残らない。
  タブ自体は削除しないため、印刷余白などタブに紐づく設定が維持される可能性がある。
  案件が無くなった場合、対応するタブは自動的に削除される）
- 1件につき1枚配置する
  （3列×8行＝24枚＝24件で1ページ。25件目以降は次の8行ブロック＝次ページに続く）

### ラベル1枚のレイアウト

各ラベルは3段のセル（縦に3行分）で構成され、行の高さは常に固定
（データの長さによって自動で広がらない）。1段目・3段目は折り返さず、
はみ出した分は途中で切れる。2段目（メニュー名）だけは2行まで折り返す。

| 段 | 内容 | 配置 | 備考 |
|----|------|------|------|
| 1段目 | `日付 企業名`（半角スペース区切り） | 左寄せ | 日付はゼロ埋めなし・年なしの `M/d` 形式（例: `7/16`）。元の値が `2026.7.16` や `2026/7/17` のように年付き・区切り文字違いでも統一される。折り返さず固定高さ |
| 2段目 | メニュー名 | 中央寄せ | 1段目より2pt小さいフォント。2行まで折り返す。全角換算30文字（`LABEL_MENU_MAX_ZENKAKU_LEN`。半角文字は0.5文字分でカウント）を超える分はあらかじめ末尾を切り捨て、2行に収まりきらず段の高さが崩れることを防いでいる |
| 3段目 | 数量 | 中央寄せ | 太字・大きめフォントで強調。折り返さず固定高さ |

列幅66mm・ラベル1枚あたりの高さ33.9mm（3段の内訳は34px/48px/46px）で列・行の
サイズを設定する。お使いのラベルシート商品の実寸がこれと異なる場合は、`Code.gs` の
`LABEL_COL_WIDTH_MM` / `LABEL_SUBROW_HEIGHTS_PX` を実際の値に合わせて調整する
（`LABEL_SUBROW_HEIGHTS_PX` の合計がラベル1枚の高さ（px）になる）。

### 印刷時の注意

1. ラベル専用スプレッドシートを開き、ファイル > 印刷でページの余白を上下約12mm・
   左右約5mm程度に設定し、拡大縮小は「なし（実際のサイズ）」にする
   - ラベル8枚分の高さは271.2mm（33.9mm×8）でA4の縦297mmとの差は25.8mm
     （片側12.9mm）しかないため、上下13mmちょうどだと0.2mm足りず最後の行が
     2ページ目にはみ出すことがある。12mm程度に少し余裕を持たせるとよい。
     それでも収まらない場合はさらに1〜2mm狭める
2. 最終ページで3列中1〜2列しか埋まらない場合でも3列とも印刷範囲に含まれるように、
   全セルへ薄いグレー（`#f2f2f2`）の罫線を引いて「データがある列」として扱われる
   ようにしている。それでも位置がずれる場合は印刷ダイアログの「書式設定 > 配置」が
   「中央」になっていないか確認し、「左」に変更する
3. まず普通紙に試し印刷し、現物のラベルシートと透かして位置がずれていないか
   確認してから本番のラベルシートに印刷することを推奨する

「ラベル作成 結果」ダイアログには、作成した案件数・メニュー件数・ラベル専用
スプレッドシートの URL が表示される。処理中にエラーが発生した案件があれば、
通常の結果に埋もれないよう「⚠️要確認」という別ダイアログで表示される。

## 注意事項

- 案件実施日・企業名は案件ファイルの**ファイル名**から読み取る（ファイル内のセルは
  読まない）。これ以外の形式（年が2桁、区切り文字なし等）を使う場合は `Code.gs` の
  `extractDateAndCompanyFromFileName_` を変更する
- ラベル作成（機能2）は各案件タブ自身のセル内容（「案件実施日」「企業名」「メニュー名」
  「数量」）を読み取る。これは機能1のファイル名解析とは別の処理
