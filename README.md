# first-repository

特定の Google ドライブフォルダにある複数のスプレッドシートファイル（ファイル名に日付を含む）から、
指定した起点日付を基準に5日分のデータを抽出し、集計用スプレッドシート内に日付ごとのタブとして
書き出す Google Apps Script（GAS）プロジェクト。

## 構成ファイル

- `Code.gs` — メインロジック
- `appsscript.json` — GAS マニフェスト（タイムゾーン、必要スコープ）
- `.clasp.json` — [clasp](https://github.com/google/clasp) 用設定。`scriptId` は実際の
  Apps Script プロジェクトの ID に書き換えてください

## セットアップ

1. 集計に使いたい Google スプレッドシートを開き、拡張機能 > Apps Script でスクリプトエディタを開く
2. このリポジトリの `Code.gs` と `appsscript.json` の内容をコピーし、スクリプトエディタ側の
   `コード.gs` / `appsscript.json` に貼り付ける（もしくは `clasp` で `.clasp.json` の
   `scriptId` を書き換えた上で `clasp push`）
3. 対象スプレッドシートを開き直す（または再読み込み）と、メニューに「日次データ取込」が追加される

## 使い方

1. 初回実行時、自動的に「設定」という名前のシートが作成される（作成直後は入力を促すアラートが出て処理は中断する）
2. 「設定」シートに以下を入力する

   | セル | 内容 | 例 |
   |------|------|----|
   | B1 | 対象フォルダの URL または フォルダID | `https://drive.google.com/drive/folders/xxxxxxxx` |
   | B2 | 各ファイル内で読み込む固定タブ名 | `Sheet1` |
   | B3 | 起点日付 | `2026/07/13` |

3. メニュー「日次データ取込」→「5日分読み込み実行」を実行する
4. 起点日付から連続5日分（起点日を含む）について、フォルダ内のスプレッドシートファイルのうち
   ファイル名にその日付（`yyyy.M.d` 形式、例: `2026.7.13`）を含むものをすべて検出し、
   各ファイルの指定タブのデータ（使用済み範囲全体）を読み込む
5. 同じ日付に該当するファイルが複数ある場合は、そのデータを縦に連結する
6. 集計結果は、集計用スプレッドシート内に日付名（例: `2026.7.13`）のタブとして書き込まれる。
   同名タブが既に存在する場合は内容をクリアしてから書き込むため、再実行しても重複しない
7. 実行完了後、日付ごとの該当ファイル数・書き込み行数・警告（タブが見つからない等）がダイアログで表示される

## 注意事項

- フォルダ内のファイルはすべて Google スプレッドシート形式であることを前提としている
- 集計用スプレッドシート自身が対象フォルダ内にある場合、自分自身は読み込み対象から自動的に除外される
- ファイル名の日付形式は `yyyy.M.d`（月日ともにゼロ埋めなし）を前提としている。異なる形式を使う場合は
  `Code.gs` の `formatDateForMatch_` を変更する
