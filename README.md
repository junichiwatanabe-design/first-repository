# 竹橋製造 タスク管理シート

## このシートでできること（30秒まとめ）

> **誰のため**: 製造部門（キッチン）のリーダー・上司  
> **何のため**: 製造以外の事務業務を見える化し、人時生産性 ¥15,000/h の達成を週次で追う  
> **やること**: タスクを入力し、週次で売上を1セル入力するだけ。あとは自動計算される

製造部門（キッチン）の**製造以外の業務（事務・発注・業者対応・試作等）**を見える化し、  
人時生産性 ¥15,000/h 達成を週次KPIで追うための Google スプレッドシートです。

## 人時生産性テーブルの使い方

`人時生産性` シートは2段構成になっています。

### 上段：労働時間テーブル（参照元確認）

勤怠シートから IMPORTRANGE で自動取得します。  
初回のみブラウザ上でアクセス許可が必要です（「許可する」をクリック）。

| 列 | 内容 |
|---|---|
| A | 担当者名（参照元シートの順番通り） |
| B〜F | 週別労働時間（1w〜5w、単位: h） |
| G | 月合計（h） |

### 下段：人時生産性テーブル（自動計算）

**黄色のセル（売上列）に今週の売上を手動入力**すると、以下が自動計算されます。

| 列 | 項目 | 計算式 |
|---|---|---|
| B | 総勤務時間(h) | 上段の合計列を参照 |
| C | 事務工数(h) | タスク一覧の実績工数をSUMIF集計 |
| D | 製造時間(h) | 総勤務時間 − 事務工数 |
| E | 事務時間率 | 事務工数 ÷ 総勤務時間（20%超=橙、30%超=赤） |
| F | **売上(円)** | **← ここを手動入力** |
| G | 人時生産性・全体 | 売上 ÷ 総勤務時間 |
| H | 人時生産性・製造のみ | 売上 ÷ 製造時間 |
| I | 目標差 | 人時生産性全体 − ¥15,000（赤=未達、緑=達成） |
| J | 製造機会損失額 | 事務工数 × ¥15,000 |
| K | 目標達成に必要な事務削減(h) | 総勤務時間 − (売上 ÷ 15,000) |

## Apps Script セットアップ手順

人時生産性シートの構築は Apps Script で行います。

1. タスク管理シートを開く
2. メニュー「**拡張機能**」→「**Apps Script**」
3. エディタに `コード.gs` の内容を貼り付ける
4. 上部のドロップダウンで `buildProductivityTable` を選択
5. 「**▷ 実行**」をクリック
6. 初回のみ「アクセスを承認」→「許可」

> **注意**: 労働時間シートのシート名が `シート1` 以外の場合、  
> スクリプト内の `LABOR_NAME` 変数を実際のシート名に変更してください。

## 人時生産性の計算構造

```
人時生産性 = 売上 ÷ 総勤務時間
製造時間   = 総勤務時間 − 事務工数（タスク管理シートの実績工数合計）
```

事務工数を削減するほど製造時間が増え、人時生産性が向上します。  
「目標達成に必要な事務削減(h)」列が、今週削減すべき目標値です。

---

## 用語説明

| 用語 | 説明 |
|---|---|
| 乖離率 | 実績工数 ÷ 予定工数。100%=予定通り、150%超=大幅超過 |
| ブロッカー | 外部要因でタスクが進められない状態 |
| 週別ワークロード（上段） | 開始〜締切を週按分した計画値 |
| 週別ワークロード（下段） | 締切がその週のタスクの実績合計 |
| 人時生産性 | 売上 ÷ 労働時間。目標 ¥15,000/h |
| 製造機会損失額 | 事務工数 × ¥15,000（その時間を製造に充てた場合の機会損失） |

## このシートのメリット・デメリット

### メリット

| # | 内容 |
|---|---|
| 1 | 事務工数を**金額（機会損失）で語れる** → 上司への改善提案が数字で通りやすくなる |
| 2 | 担当者別の**工数偏り・過負荷**が一目でわかる |
| 3 | 「目標達成にあと何h削減すればいいか」が**即座に算出**される |
| 4 | タスクの乖離率で**見積もりの甘い業務**を特定できる |

### デメリット・注意点

| # | 内容 | 対策 |
|---|---|---|
| 1 | **毎週の入力が前提**。止まると数字が実態を反映しなくなる | 週次レビューと入力を習慣化する |
| 2 | **売上の定義・入力ルール**を決めないと週ごとに比較できない | 「部門売上÷チーム人数」など基準を先に決める |
| 3 | カテゴリが「その他」に偏ると**事務の中身が見えない** | カテゴリを具体化（発注/業者対応/試作 など） |
| 4 | 製造時間は**推定値**（勤務時間−事務工数）。実測ではない | あくまで目安として使い、精度より継続を優先 |
